# 基于 YOLOv8 与 API 579 FFS 的焊接缺陷自动识别与评估系统

<p align="center">

**Welding Defect Detection and Assessment System Based on YOLOv8 and API 579 FFS**

</p>

<p align="center">

基于机器视觉的焊接缺陷自动识别、尺寸评估与工程完整性辅助评价系统

</p>

---

## 📖 项目简介

本项目是一套面向焊接缺陷检测与工程评价的自动化辅助分析系统。

系统以 **YOLOv8** 为核心视觉检测模型，通过图形化界面引导用户选择待评定的缺陷类型、输入检测图像及相关工程参数，并利用 YOLOv8 对 X 射线探伤设备获取的焊接缺陷灰度图像进行自动识别。

在完成缺陷识别后，系统进一步结合**滑动窗口算法**对缺陷区域进行细分和尺寸参数计算，并根据 **API 579 Fitness-For-Service（FFS）** 相关评定方法对缺陷进行工程评价，最终在原始图像上标注缺陷位置及评定结果，并可自动生成检测报告。

系统的整体处理流程为：

```text
X射线探伤灰度图像
        │
        ▼
┌─────────────────────┐
│    缺陷类型选择      │
│   Crack / LP / PO   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│      YOLOv8          │
│   缺陷自动识别与定位  │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     滑动窗口处理      │
│ 缺陷区域细分与尺寸计算 │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     API 579 FFS      │
│      工程评定         │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│    结果可视化标注     │
│      合格 / 不合格    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│     检测结果报告      │
│       Word 报告       │
└─────────────────────┘
```

## ✨ 项目特点

### 1. 基于 YOLOv8 的自动缺陷识别

使用训练完成的 YOLOv8 模型对输入的焊接缺陷图像进行目标检测，自动获取缺陷的位置及相关检测信息。

### 2. 滑动窗口缺陷评估

针对 YOLOv8 检测得到的缺陷区域进一步进行滑动窗口处理，将较大的缺陷区域划分为多个子区域，并分别计算相关几何参数。

### 3. API 579 FFS 工程评价

根据缺陷区域的几何特征及材料相关参数，结合 API 579 相关评定方法，对检测区域进行工程辅助评价。

### 4. 图形化操作界面

使用 Tkinter 构建 GUI，无需直接修改代码即可完成：

* 缺陷类型选择
* 检测图像目录选择
* 原图像尺寸输入
* 容器壁厚输入
* 材料参数输入
* API 579 相关参数输入
* 检测任务启动

### 5. 自动结果标注

使用 OpenCV 对检测结果进行可视化，在原始图像上标注：

* 缺陷位置
* 缺陷尺寸
* 评定结果

其中：

* 🟩 **绿色框：通过评定**
* 🟥 **红色框：未通过评定**

### 6. 自动生成检测报告

检测完成后，系统可以自动生成 Word 格式的检测报告，对检测及评定结果进行整理。

# 🧠 核心算法

## 1. YOLOv8 目标检测

系统首先加载训练完成的 YOLOv8 模型，对输入的 X 射线焊接缺陷灰度图像进行推理。

模型输出包括缺陷相关的检测信息，例如：

* 缺陷位置
* 边界框坐标
* 置信度

基本流程：

```text
输入图像
   │
   ▼
YOLOv8
   │
   ▼
缺陷边界框
   │
   ├── 缺陷位置
   └── 置信度
```

---

## 2. 滑动窗口算法

对于 YOLOv8 检测到的缺陷区域，系统进一步采用滑动窗口算法进行处理。

其主要思想是：

```text
YOLO 检测区域
┌──────────────────────────┐
│                          │
│   ┌────┐                 │
│   │ W1 │                 │
│   └────┘                 │
│       ┌────┐             │
│       │ W2 │             │
│       └────┘             │
│           ┌────┐         │
│           │ W3 │         │
│           └────┘         │
│                          │
└──────────────────────────┘
```

通过对不同子窗口分别进行处理，可以进一步获得缺陷区域的相关几何特征。

手册中所描述的相关参数包括：

* 缺陷长度
* 缺陷宽度
* 缺陷面积

---

# 📐 API 579 FFS 评定

系统在视觉检测基础上进一步引入 API 579 Fitness-For-Service（FFS）相关评定方法。

整体过程为：

```text
YOLOv8 缺陷检测
        │
        ▼
缺陷区域提取
        │
        ▼
滑动窗口处理
        │
        ▼
几何参数计算
        │
        ├── 长度
        ├── 宽度
        └── 面积
        │
        ▼
材料及工程参数
        │
        ▼
API 579 评定
        │
        ▼
通过 / 未通过
```

裂纹缺陷的评定还需要输入额外的工程参数，包括：

* 钢材类型
* API 579 评定曲线类型
* 最小屈服强度（MYS）
* 相关材料参数

系统根据输入的缺陷几何特征和工程参数进行计算，并结合相应评定曲线及数据表完成评定。

# 🧭 使用流程

## Step 1：选择缺陷类型

启动程序后，首先进入缺陷类型选择器。

根据需要选择对应的缺陷评定程序。

当前系统包含：

* 裂纹（CR）
* 未焊透（LP）
* 气泡（PO）

---

## Step 2：输入检测参数

选择缺陷类型后，系统会启动对应的评定程序，并弹出参数输入窗口。

根据 GUI 提示输入相关信息。

一般包括：

```text
待检测图片目录
原图像长度
原图像宽度
容器壁厚
```

裂纹缺陷还需要额外输入：

```text
钢材类型
API 579 评定曲线类型
最小屈服强度（MYS）
其他相关工程参数
```

---

## Step 3：开始检测

完成参数输入后，点击：

```text
开始检测
```

程序会自动：

1. 读取指定目录中的检测图像
2. 调用 YOLOv8 模型
3. 识别焊接缺陷
4. 获取缺陷位置
5. 对缺陷区域执行后续处理
6. 使用滑动窗口算法进行评定
7. 根据 API 579 相关方法进行工程评价
8. 在图像上绘制检测结果
9. 保存处理后的图片
10. 生成检测报告

# 🎯 项目定位

本项目并非单纯的 YOLOv8 图像目标检测程序，而是尝试将：

```text
机器视觉
    +
深度学习目标检测
    +
缺陷几何参数分析
    +
API 579 FFS 工程评价
    +
自动化报告生成
```

整合为一个完整的焊接缺陷辅助检测与评估流程。

其核心目标是实现：

> **从 X 射线焊接检测图像中的缺陷自动识别，到缺陷区域分析，再到工程评价和结果报告生成的自动化辅助流程。**

---

# ⚠️ 注意事项

1. 本项目使用的检测结果依赖于 YOLOv8 模型本身的检测性能。
2. API 579 相关评定结果依赖用户输入的材料、尺寸及其他工程参数。
3. 输入参数应根据实际检测对象和适用的工程条件正确填写。
4. 系统输出结果用于辅助分析，不应在缺少专业工程人员审核的情况下直接作为实际工程安全决策的唯一依据。
5. API 579 相关计算和评定应结合适用的正式标准、工程条件及专业人员判断进行确认。
